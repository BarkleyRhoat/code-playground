# code-playground

A personal sandbox for testing ideas, experimenting with new tech, and practicing concepts.

## What's here

Currently exploring basic funadmentals of programming using HTML, CSS and JS

## Setup

### 1. Clone the repo via SSH

```bash
git clone git@github.com:<your-username>/code-playground.git
cd code-playground
```

### 2. Create a new branch

> **Never work directly on the `main` branch.**

```bash
git checkout -b your-branch-name
```

### 3. Push your branch

```bash
git push origin your-branch-name
```

Then go to the repo page on GitHub and click **Compare & pull request** to open a PR against `main`.
